# Ombrelune Studio

Page du studio qui réunit ses deux jeux de fans : [Idlus](https://idlus.github.io/) et [Diablofus : Les Douze Enfers](https://diablofus.com/).

Site fixe sans build : `index.html`, `style.css`, `app.js` (lit les nouveautés des deux jeux à chaque visite), `img/`.
Publié par GitHub Pages depuis `main`.

Idlus et Diablofus sont des jeux de fans gratuits, non officiels et non affiliés à Ankama. DOFUS est une marque d'Ankama.
